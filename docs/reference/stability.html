Stability#

ChartBook is experimental. It is in early development and anything can change from one release to the next: the chartbook.toml format, the commands, the Python functions, and the files it writes.

Breaking changes are listed in the changelog, marked breaking, with what to do about each.

If you depend on ChartBook for something that must keep working, pin the version you tested with:

chartbook==0.4.0

A real stability promise will come with 1.0.

Some parts are earlier still. Reading a source in a Databricks SQL warehouse (backend = "databricks") has been tested only against a stand-in for the warehouse, and is likely to change more than the rest. The Roadmap says what is experimental and what is next.
