chartbook.data#

Catalog-aware data loading for chartbook.

Load dataframes from registered pipelines in a catalog::

from chartbook import data

# Load as Polars LazyFrame (default)
lf = data.load(pipeline="yield_curve", dataframe="repo_public")

# Load as Polars eager DataFrame
df = data.load(pipeline="yield_curve", dataframe="repo_public", format="polars_eager")

# Load as pandas DataFrame
df = data.load(pipeline="yield_curve", dataframe="repo_public", format="pandas")

# Get just the data path
path = data.get_data_path(pipeline="yield_curve", dataframe="repo_public")

# Get documentation content
docs = data.get_docs(pipeline="yield_curve", dataframe="repo_public")

# Get path to documentation source
docs_path = data.get_docs_path(pipeline="yield_curve", dataframe="repo_public")

chartbook.data.get_data_path(pipeline: str, dataframe: str, catalog_path: Optional[Union[str, pathlib.Path]] = None) → pathlib.Path[source]#

Get the resolved path to a dataframe’s parquet file.

For glob patterns (e.g., **/*.parquet), returns a Path containing the glob pattern characters.

Parameters:

  • pipeline (str) – The pipeline reference — a bare name ("crsp_treasury", if unambiguous), a scoped ID ("ftsfr/crsp_treasury"), or a repository URL.

  • dataframe (str) – The dataframe identifier within the pipeline.

  • catalog_path (Optional[Union[str, Path]]) – Path to a catalog chartbook.toml or its parent directory. If None, the global default from ~/.chartbook/settings.toml is used.

Returns:

The resolved path to the parquet file (may contain glob characters).

Return type:

Path

Raises:

  • CatalogNotConfiguredError – If no catalog is configured.

  • KeyError – If the pipeline or dataframe is not found.

chartbook.data.get_docs(pipeline: str, dataframe: str, catalog_path: Optional[Union[str, pathlib.Path]] = None) → str[source]#

Get the documentation content for a dataframe as a string.

Works with both documentation modes:

  • If the dataframe uses docs_path, reads and returns the content of the .md file.

  • If the dataframe uses docs, returns the inline string directly.

Parameters:

  • pipeline (str) – The pipeline reference — a bare name ("crsp_treasury", if unambiguous), a scoped ID ("ftsfr/crsp_treasury"), or a repository URL.

  • dataframe (str) – The dataframe identifier within the pipeline.

  • catalog_path (Optional[Union[str, Path]]) – Path to a catalog chartbook.toml or its parent directory. If None, the global default from ~/.chartbook/settings.toml is used.

Returns:

The documentation content as a string.

Return type:

str

Raises:

  • CatalogNotConfiguredError – If no catalog is configured.

  • KeyError – If the pipeline or dataframe is not found.

chartbook.data.get_docs_path(pipeline: str, dataframe: str, catalog_path: Optional[Union[str, pathlib.Path]] = None) → pathlib.Path[source]#

Get the path to a dataframe’s documentation source.

For dataframes using docs_path, returns the path to the .md file. For dataframes using docs (inline docs), returns the path to the chartbook.toml file where the docs are defined.

Parameters:

  • pipeline (str) – The pipeline reference — a bare name ("crsp_treasury", if unambiguous), a scoped ID ("ftsfr/crsp_treasury"), or a repository URL.

  • dataframe (str) – The dataframe identifier within the pipeline.

  • catalog_path (Optional[Union[str, Path]]) – Path to a catalog chartbook.toml or its parent directory. If None, the global default from ~/.chartbook/settings.toml is used.

Returns:

The resolved path to the documentation source file.

Return type:

Path

Raises:

  • CatalogNotConfiguredError – If no catalog is configured.

  • KeyError – If the pipeline or dataframe is not found.

chartbook.data.load(pipeline: str, dataframe: str, format: str = 'polars', catalog_path: Optional[Union[str, pathlib.Path]] = None)[source]#

Load a dataframe from a registered pipeline in a catalog.

Parameters:

  • pipeline (str) – The pipeline reference — a bare name ("crsp_treasury", if unambiguous), a scoped ID ("ftsfr/crsp_treasury"), or a repository URL.

  • dataframe (str) – The dataframe identifier within the pipeline.

  • format (str) – Output format — "polars" (default, returns LazyFrame), "polars_eager", "pandas", or "polars-lazyframe" (deprecated alias for "polars"). Glob patterns in a dataframe’s path only support "polars" (LazyFrame).

  • catalog_path (Optional[Union[str, Path]]) – Path to a catalog chartbook.toml or its parent directory. If None, the global default from ~/.chartbook/settings.toml is used.

Returns:

The loaded dataframe in the requested format.

Return type:

pandas.DataFrame or polars.DataFrame or polars.LazyFrame

Raises:

  • CatalogNotConfiguredError – If no catalog is configured.

  • KeyError – If the pipeline or dataframe is not found.

  • ValueError – If format is not one of the supported values, or if a glob path is used with a non-LazyFrame format.

Examples

Load as a Polars LazyFrame (default):

from chartbook import data lf = data.load(pipeline=“yield_curve”, dataframe=“repo_public”, … catalog_path=“/path/to/catalog”) # doctest: +SKIP

Load as a Polars eager DataFrame:

df = data.load(pipeline=“yield_curve”, dataframe=“repo_public”, … format=“polars_eager”, … catalog_path=“/path/to/catalog”) # doctest: +SKIP

Load as a pandas DataFrame:

df = data.load(pipeline=“yield_curve”, dataframe=“repo_public”, … format=“pandas”, … catalog_path=“/path/to/catalog”) # doctest: +SKIP
