chartbook.refs#

The reference grammar: one parser from text to a structured address.

An asset is addressed by a reference::

[registry/][scope/]pipeline : [kind/]name [#part] [@rev]

Each separator asks a different question, read left to right:

/ One level down: registry, then scope, then pipeline; kind, then name. : “From this pipeline, take…”. Everything before it says which pipeline; everything after says what inside it. A reference with no colon is local: it names an asset of the pipeline you are in. # “…this part of it”: a column of a dataframe, a file inside a model. @ “…at this revision”: a version of the asset.

The kind defaults to dataframe, because data is what gets passed around; every other kind says what it is. So treasury_rates is a dataframe, chart/gdp a chart, model/rate_forecaster a model and file/filings a files asset.

This module only parses and formats. It accepts the whole grammar, and knows nothing about which parts of it can be resolved yet; that is

mod:

chartbook.resolve’s business. Everything inside ChartBook should carry an :class:AssetRef, not a string, once a reference has been read.

The specification, with the reasoning and the prior art, is docs_src/design/references.md.

class chartbook.refs.AssetRef[source]#

A parsed reference to an asset: the address as named fields.

This is the form to pass around in code and to write as JSON. The text form is for people, command lines and chartbook.toml; str() of an AssetRef gives it back, and :func:parse_asset_ref reads it.

The fields are in the order they are written. An AssetRef is checked when it is made, so one that exists is well-formed.

Attributes: registry: The registry that resolves the pipeline, if given. scope: The pipeline’s scope (its organization), if given. pipeline: The name of the pipeline that declares the asset, or None for a local reference (an asset of the pipeline you are in). kind: What kind of asset it is; one of :data:KINDS. name: The asset’s name: its key in its table of chartbook.toml. part: A part inside the asset, if one is addressed. rev: The revision of the asset, if one is pinned.

chartbook.refs.parse_asset_ref(text: Union[str, chartbook.refs.AssetRef], kind: Optional[str] = None) → chartbook.refs.AssetRef[source]#

Parse the text of a reference to an asset.

The whole grammar is accepted. Whether a given reference can be resolved yet is a separate question, answered by

Func:

chartbook.resolve.resolve.

Parameters:

  • text – The reference, e.g. "treasury_rates", "chart/gdp" or "ftsfr/fed_yield_curve:model/forecaster@v3". An AssetRef is checked against kind and returned.

  • kind – The kind the caller expects. A reference that names no kind takes this one; a reference that names a different kind is an error. When None, a reference that names no kind is a dataframe.

Returns:

The parsed reference.

Raises:

  • KindMismatchError – If the reference names a kind other than kind.

  • ValueError – If the text does not follow the grammar.
