chartbook.identity#

Pipeline identity: scoped names, URL normalization, and reference resolution.

The canonical identity of a pipeline is a scoped name scope/name (e.g. ftsfr/crsp_treasury) or a bare name for local-only projects. URLs are accepted as input wherever a pipeline reference is taken and are normalized to scoped names; they are never stored as identity.

Two extensions of the grammar are reserved: recognized by the parser, and refused with a “not yet supported” error rather than a grammar error, so that they can be given meaning later without changing what any existing ID means.

  • scope/name@rev — a pinned revision.

  • registry/scope/name — an ID qualified with the registry that resolves it, Docker-style, e.g. charthub.example/acme/rates.

See the format design doc (docs_src/design/toml-format-v2.md) for the rationale behind this scheme, and “Reserving a future global namespace” in docs_src/design/asset-graph.md for the registry prefix.

chartbook.identity.derive_pipeline_id(project: dict, base_dir: pathlib.Path | str) → str[source]#

Derive a pipeline’s canonical ID.

Precedence:

  1. Explicit id in the [project] table.

  2. The pipeline a laid-out version’s :data:VERSION_FILE names.

  3. With a repository address, repo_url or else the git origin remote, the scope from it (:func:id_from_address); and the name from it too when the directory is the top of its git repository, else the directory’s name. So a clone, a git worktree or a renamed folder of one repository is one pipeline, whatever its folder is called, and each pipeline in a repository’s subfolders is named by its subfolder. A repo_url comes first, so a fork whose manifest names its upstream keeps the upstream’s ID.

  4. Bare directory name.

A name is lowercase snake_case, from the folder or from the remote: first-pipeline is first_pipeline; a scope is in lowercase.

Parameters:

  • project – The raw [project] table from chartbook.toml.

  • base_dir – The pipeline’s root directory.

Returns:

A validated bare or scoped pipeline ID.

chartbook.identity.id_from_address(address: str) → Optional[str][source]#

The ID a pipeline at the top of the repository at an address derives: scope/name, or a bare name.

The address is a repository’s web address or its git remote, in any of the forms git takes (https://, ssh://, user@host:path, host:path), with the host, any user, port and .git left out: git@github.com:Acme/CRSP-Treasury.git is acme/crsp_treasury. The scope is in lowercase and the name is written as a folder’s is (:func:_sanitize_component), so that every way of writing one address, on every machine, gives one ID. A remote that is a path on disk names no repository, and gives None; so does a name of nothing but dots (_.._), which names no component.

chartbook.identity.in_another_case(keys: Iterable[str], ref: str) → Optional[str][source]#

The one ID among keys that a reference names but for the case of its letters; None if none, or several.

A scope derived from a remote is in lowercase, so a reference written as a web page shows its owner (Acme/rates) misses it: this is what to suggest.

chartbook.identity.looks_like_registry(component: str) → bool[source]#

Tell whether an ID’s leading component names a registry, not a scope.

The rule is Docker’s: a component containing . or :, or equal to localhost, is a host. charthub.example and localhost:5000 are registries; acme is a scope.

Parameters:

component – The leading component of a three-component ID.

chartbook.identity.match_pipeline_ref(keys: Iterable[str], ref: str, where: str = 'this catalog') → Optional[str][source]#

Match a user-supplied pipeline reference against a set of pipeline IDs.

Matching order:

  1. Exact match on the (possibly scoped) key.

  2. URL references are normalized to scope/name and matched exactly, as written and then as the ID rule derives one from the address (:func:id_from_address): https://github.com/ftsfr/crsp-treasury matches ftsfr/crsp_treasury.

  3. A bare name matches any key whose name component equals it — but only if exactly one does; multiple matches raise an error listing the candidates.

Finding nothing is not an error here, so that a caller with somewhere else to look can go on to it. :func:resolve_pipeline_ref is this function for a caller with nowhere else.

Parameters:

  • keys – The pipeline IDs to match against: a catalog’s keys, or those of a [dependencies] table.

  • ref – The reference to match (bare, scoped, or URL).

  • where – What keys are the keys of, to say where a name is ambiguous.

Returns:

The matching key, or None if there is none.

Raises:

  • UnsupportedRevisionError – If the reference carries @rev.

  • UnsupportedRegistryError – If the reference carries a registry prefix.

  • KeyError – If a bare name matches more than one key.

chartbook.identity.normalize_ref_to_id(ref: str) → str[source]#

Normalize any accepted pipeline reference form to an ID.

Accepted forms:

  • name or scope/name — returned as-is

  • https://github.com/scope/name (or any URL) — reduced to the last two path segments, with a trailing .git (in any case) stripped

  • git@github.com:scope/name.git — same reduction

Parameters:

ref – The pipeline reference.

Returns:

A bare or scoped pipeline ID.

Raises:

  • UnsupportedRevisionError – If the reference carries @rev.

  • UnsupportedRegistryError – If the reference is qualified with a registry, e.g. charthub.example/acme/rates.

  • ValueError – If nothing ID-like can be extracted.

chartbook.identity.plain_line(value: object, longest: int = 10000) → str[source]#

Text someone else wrote, as one line of what can be seen; empty if nothing can.

Characters that do not print (controls, format characters, lone surrogates) become spaces, and runs of space become one; the text is otherwise as written. Text with no character that shows (only spaces, fillers or combining marks) is no text. It is read only as far as the length kept, so that a long value costs nothing.

Parameters:

longest – Cut to this many characters.

chartbook.identity.read_version_file(base_dir: pathlib.Path | str) → dict[source]#

What a laid-out version’s :data:VERSION_FILE says; empty unless the folder is one.

A folder is a laid-out version when it has the file and is not a repository’s own folder: no .git in it, and the file not tracked by git. A laid-out folder copied to start a new pipeline and committed is that new pipeline, not the old version. A file too large, or not a JSON object, is not read.

chartbook.identity.remote_to_web_url(remote: Optional[str]) → str[source]#

Turn a git remote into the web address of the repository it names.

A remote is written for git, not for a browser, and may carry things that must not be published. This reduces it to https://host/path:

  • git@github.com:acme/rates.git → https://github.com/acme/rates

  • ssh://git@gitlab.internal:2222/acme/rates.git → https://gitlab.internal/acme/rates

  • https://user:token@github.com/acme/rates.git → https://github.com/acme/rates

Credentials embedded in the remote are always dropped. A remote that is a path on disk has no web address and gives an empty string; a Windows path with a drive letter, C:\repos\rates or C:/repos/rates, is one, as git reads it, and not a host C.

Parameters:

remote – The remote URL, as git config remote.origin.url prints it.

Returns:

A web URL, or "" if the remote does not name a host.

chartbook.identity.repository_key(address: Optional[str]) → str[source]#

A repository’s address, reduced so that the ways of writing one repository give one key.

git@github.com:Acme/Rates.git, https://github.com/acme/rates/ and http://github.com:443/acme/rates are one repository: the scheme is taken as https, the host in lower case with no default port, the path with no .git or final slash, and in lower case for a host that ignores its case.

Returns:

The key, or "" for no address or one with no host.

chartbook.identity.same_pipeline_checked_out(first: Optional[chartbook.identity.Checkout], second: Optional[chartbook.identity.Checkout]) → bool[source]#

Whether two folders are one pipeline in two checkouts of one repository, at the same place in it.

Two worktrees of one repository share its git folder. Two clones are one repository as a pin takes one: by the address of their remotes where both have one, so that two repositories made from one template (one first commit, two addresses) are two; by their first commit where either has none.

chartbook.identity.split_registry(pipeline_id: str) → tuple[Optional[str], str][source]#

Split a registry prefix off a fully qualified pipeline ID.

A registry-qualified ID has exactly three components, registry/scope/name, and its first looks like a host (see

Func:

looks_like_registry). Anything else has no registry: a bare name and a scope/name are returned whole, whatever characters the scope contains, so no ID that was valid before the prefix was reserved changes meaning.

Parameters:

pipeline_id – A pipeline ID, or a reference that starts with one (a trailing :asset does not affect the split).

Returns:

Tuple of (registry or None, the ID without it).

chartbook.identity.split_rev(ref: str) → tuple[str, Optional[str]][source]#

Split an @rev suffix off a pipeline reference.

URLs are passed through untouched (an @ may be part of ssh syntax).

Parameters:

ref – A pipeline reference, possibly with an @rev suffix.

Returns:

Tuple of (reference without rev, rev or None).

chartbook.identity.strip_url_credentials(url: str) → str[source]#

Take any user name and password out of a repository URL.

For anything that shows or publishes a URL a manifest wrote: an index, a warning in a CI log. https://user:token@host/… becomes https://host/…. An ssh URL keeps its user (ssh://git@host/…), which is part of the address and not a secret, and loses only a password. A URL with no scheme (git@host:acme/rates.git, a path on disk) is returned as it is.

Unlike :func:remote_to_web_url, the result is still the address git fetches from.

Parameters:

url – The URL as written.

Returns:

The URL without credentials.

chartbook.identity.validate_pipeline_id(pipeline_id: str) → str[source]#

Validate a pipeline ID against the [scope/]name grammar.

Parameters:

pipeline_id – The candidate ID, e.g. "ftsfr/crsp_treasury" or a bare "crsp_treasury".

Returns:

The validated ID, unchanged.

Raises:

  • ValueError – If the ID has more than two components or a component contains disallowed characters.

chartbook.identity.web_link(value: object) → str[source]#

The value if it is a plain web address (http or https), with no credentials; else an empty string.

For a link whose text someone else wrote, as a pipeline’s snapshot in the store says where its repository and site are: a javascript: link, or one that would break out of the page’s markup, is no link.

Parameters:

value – The address as written.

Returns:

The address, or "".
