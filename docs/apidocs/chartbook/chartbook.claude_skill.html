chartbook.claude_skill#

The Claude Code skill ChartBook ships: where it is installed, and which ChartBook it was written for.

The skill’s entry point, SKILL.md, names the ChartBook version it describes in its front matter::

metadata:
  chartbook-version: "0.2.0"

A release keeps that equal to the package’s version (a test does). An installed copy is then compared with the ChartBook that is running: chartbook install claude-skill says what it replaced, chartbook check warns, and any other command, run by a person at a terminal, says so in one line (:func:chartbook.cli._say_if_the_skill_is_stale). Nothing here ever stops a command.

chartbook.claude_skill.project_dir(start: Optional[pathlib.Path | str] = None) → Optional[pathlib.Path][source]#

The project’s copy of the skill: .claude/skills/chartbook in start or the nearest folder above it that has one.

Claude Code reads a project’s .claude at the folder it was started in, usually the repository’s top, which may be above a pipeline in a subfolder. So the walk goes up to the top of the git repository start is in, and never reaches the home folder, whose .claude is the user’s own; nor is the user-level copy, wherever it is, a project’s. A folder that cannot be read is passed by.

Parameters:

start – Where to look from; the working directory by default.

Returns:

The folder, or None if there is none.

chartbook.claude_skill.relation(directory: pathlib.Path) → str[source]#

How a copy stands to this ChartBook: "current", "newer" or "older".

"newer" is a copy whose front matter names a later version than this package’s: written for a newer ChartBook installed elsewhere (each pipeline may have its own environment), and nothing to replace from here. Anything else that is not this version (a stamp only, no version, one that is not a version) is "older".

chartbook.claude_skill.shown(path: pathlib.Path) → str[source]#

chartbook.claude_skill.stale(start: Optional[pathlib.Path | str] = None) → list[chartbook.claude_skill.Copy][source]#

The installed copies of the skill written for an older ChartBook than this one: the project’s, then the user’s.

A copy for a newer ChartBook is not said: installing this one’s would undo the newer one, and the two environments would take turns.

Parameters:

start – Where the project’s copy is looked for from (:func:project_dir).

chartbook.claude_skill.user_dir() → pathlib.Path[source]#

Where the user-level skill is: $CLAUDE_CONFIG_DIR/skills/chartbook, or ~/.claude/skills/chartbook.

chartbook.claude_skill.version_of(directory: pathlib.Path) → Optional[str][source]#

Which ChartBook an installed copy was written for, as far as it says.

Its SKILL.md’s front matter (:func:front_matter_version); for a copy installed before the version was there, the stamp file beside it (:data:OLD_STAMP). The bundled skill always names its version in its front matter, so a copy that names it only in a stamp is never the current one, whatever the stamp says (:func:relation).

Returns:

The version, or None if the copy names none.
