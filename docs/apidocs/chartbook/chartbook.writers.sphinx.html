chartbook.writers.sphinx#

The Sphinx writer: pages for Sphinx, from the index and the files it names.

The slices so far are the dataframe, chart, model, files and pipeline pages. Each renders today’s templates with a context built from the record, its pipeline’s record, the records of its inputs or assets and the files the records name, and writes the same page the generator writes, which a golden test holds it to. The “manifests” the templates read are made here from the records; the templates are unchanged until the generator is gone, so that the two can be compared.

assistant_file() → str[source]#

The site as an assistant reads it: one line per pipeline, dataframe, chart, model and files asset, with where its page is.

In the llms.txt form: the site’s name as the title, what it is as the summary, then a list per kind, each line - [name](page): `ID`. “Description”, every link relative to the site’s root, where the file is. In a catalog, each pipeline’s line has its newest versions under it, each linking the version site’s own assistant file. The records in full are in index.json beside it.

What a record’s owner wrote (a name, a description) is one line, with what would start a link, an autolink or code escaped, and a description is always in quotation marks after words of the file’s own, so that it never starts a line: it can make no heading, list or link of its own, and reads as the owner’s words. The summary is the file’s own words only.

The Markdown page of one model, from its record, its inputs’ records and the write-up.

Everything on the page is in the record: scores, versions, files, what it was trained on (its inputs), and whether it is out of date (stale_inputs). The Markdown page of one pipeline, from its record, its assets’ records and the files they name.

chartbook.writers.sphinx.freshness_fact(label: str, moment: Optional[datetime.datetime]) → Optional[dict][source]#

One “

The page says when, not how long ago: a generated page is static, so “2 days ago” worked out at build time would be wrong the next day, and would make every page differ from one build to the next. The timestamp goes into a <time> element and chartbook-freshness.js turns it into relative wording when the page is read.

Every time on the site is in UTC and says so, whatever the zone of the machine that built it: a naive moment is taken as that machine’s local time and converted.

Returns:

label, iso (ISO 8601 with offset), title (hover text) and date (fallback text); None when moment is None.
