chartbook.hashing#

Content hashes: the one way ChartBook names the bytes of an asset.

Hash computation is singular on purpose. Two implementations that hashed differently would make no two indexes comparable, so everything that needs the hash of an asset calls this module, and the rules below are part of the index specification (docs_src/design/index-schema.md, “Hashes”).

A hash is written "<algorithm>:<hex>", e.g. "sha256:7f3a9c...".

  • A file is hashed as its bytes.

  • Several files, the matches of a glob or the contents of a directory, are hashed as a listing with one line per file::

    <hex of the file's SHA-256>  <relative/path/with/forward/slashes>\n

    sorted by path. This is the output of sha256sum, so the result can be reproduced by hand::

    cd _data/rates && find . -type f | sed 's|^\./||' \
    | grep -viE '(^|/)(\.DS_Store|Thumbs\.db|desktop\.ini|\._[^/]*)$' \
    | LC_ALL=C sort | xargs sha256sum | sha256sum

    The grep leaves out the few files that operating systems create by themselves (:func:is_ignored). Every other file counts, hidden or not.

Hashing reads every byte, and data files are large, so a

class:

HashCache remembers each file’s hash against its size and modification time. A file whose size and time are unchanged is not read again. That is the same bet git makes, and it loses in the same case: a file rewritten with identical size and identical timestamp.

chartbook.hashing.escapes(path: Union[str, pathlib.Path], root: Union[str, pathlib.Path]) → Optional[pathlib.Path][source]#

The first file a declared path reaches outside root, or None.

A manifest’s path is joined to the pipeline’s directory, but it may be absolute, climb with .., or be a symlink; and a file inside the directory may itself be a link to one outside. Every file the path names is followed to where it really is. This is what keeps a pipeline that is only read (a git dependency being pinned, a snapshot being made) from reaching anything but its own files.

Parameters:

  • path – The declared path, made absolute, possibly a glob.

  • root – The directory the files must be within.

Returns:

The real path of the first file outside root, or None if every file is inside it or there are no files.

chartbook.hashing.is_ignored(name: Union[str, pathlib.Path]) → bool[source]#

Whether a file is one of the few that are never part of an asset.

These are .DS_Store, Thumbs.db, desktop.ini and anything whose name starts with ._, compared without regard to case. The list is short and fixed on purpose. A hidden file is content unless it is on it: a Zarr dataset keeps its metadata in .zarray.

The rule applies to an asset made of several files, a directory or a glob. A path that names one file is that file, whatever it is called.

Parameters:

name – A file’s name, or a path whose last component is one.
