chartbook.lineage#

The lineage of a pipeline: every snapshot upstream of it, walked through the pins, and checked.

A snapshot records what its pipeline was pinned to (inputs): for each dependency, the commit and time of the snapshot pinned and one hash over everything pinned from it (pinned_hash). Those snapshots record theirs, and so on up: a graph whose every edge is a hash. :func:walk follows it up from a pipeline’s own lockfile and checks each edge:

  • the snapshot an edge names is in the store and can be read;

  • what was pinned from it is what it holds: each asset at its hash, for the pipeline’s own lockfile (:func:chartbook.snapshot.lineage_gaps); the hash over everything pinned, recomputed from the snapshot as a pin would make it, for a snapshot’s recorded input;

  • each snapshot’s recorded inputs cover every dependency its own manifest declares, the manifest kept with it in the store (a snapshot made before snapshots checked their pins may not);

  • each asset of each snapshot is in the store, and with rehash still hashes to its name.

A git dependency is pinned from its clone, not from a snapshot, so the walk stops there and says so. A snapshot met twice is walked once. Nothing is written.

class chartbook.lineage.Node[source]#

One pipeline in the lineage: the folder it starts from, or a snapshot upstream.

Attributes: label: How the pipeline below names it: its key in [dependencies], or, at the top, the pipeline’s ID. pipeline: The pipeline’s ID, as its snapshot names it; empty when no snapshot was found. commit: The commit of the snapshot, or of a git dependency’s clone. made_at: When the snapshot was made. kind: working (the folder the walk starts from), snapshot, git (pinned from a clone; not walked further), no_snapshot (a pin that names no snapshot, as one in a lockfile changed by hand does), nothing (nothing pinned), missing (no such snapshot in the store), mismatch (the snapshot is there and does not hold what was pinned) or unreadable (a record that is not one ChartBook wrote). gaps: What is wrong at this point of the lineage, one line each. children: The pipelines it was pinned to. seen: Whether this snapshot was met before in the walk, and is shown there. checked: How the snapshot’s lineage was checked when it was made, as its record says: pins, deep, or empty for one made before snapshots checked their pins.

chartbook.lineage.walk(project_dir: Union[str, pathlib.Path] = '.', store: Optional[chartbook.store.Store] = None, rehash: bool = False) → chartbook.lineage.Lineage[source]#

Walk a pipeline’s lineage up from its lockfile, through every snapshot it leads to, and check each edge.

What is read from the store was written by whoever can write to it, so a record that is not what ChartBook writes is a gap where it is met, never an error that stops the walk.

Parameters:

  • project_dir – The pipeline’s folder.

  • store – The store; this user’s by default.

  • rehash – Also hash every asset of every snapshot again, and every model version a label pinned, which reads all their bytes.

Raises:

chartbook.snapshot.SnapshotError – If the folder holds no pipeline.
