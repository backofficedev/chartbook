chartbook.files#

Files: the front door for assets that are not tables.

A files asset is a file, a folder of files or a glob of them, that a pipeline declares in [files], whatever is inside: gzipped JSON lines, text, HTML, PDFs, images, NumPy arrays, a SQLite file, a vendor’s zip. ChartBook moves, versions and documents the bytes. It does not read them: the one exception is a short preview on the asset’s page, at most

data:

PREVIEW_BYTES of one file. Reading is one line of your own code::

import gzip, json from chartbook import assets

for path in assets.files(“file/earnings_releases”): with gzip.open(path, “rt”) as f: records = [json.loads(line) for line in f]

func:

chartbook.assets.files gives the files, sorted, and

func:

chartbook.assets.index a table of them, with their sizes, hashes and the keys of any key=value folders, to pick files from before opening any. Both work for every asset with files, a dataframe’s too.

func:

path here is :func:chartbook.assets.path with the kind fixed, as

func:

chartbook.models.path is for models.

A snapshot, a pin, chartbook update, restore, lineage and store gc treat a files asset as any other: its hash is the hash of its file, or of the listing of its files (:mod:chartbook.hashing).

chartbook.files.count_by_extension(names: Iterable[str], most: int = TYPES_COUNTED) → dict[str, int][source]#

How many files there are of each type (:func:extension), the most common first; "" for those with none.

At most most types are named; the files of the rest are counted together under :data:OTHER_TYPES, so that 20,000 files of 20,000 made-up endings make one line and not 20,000.

chartbook.files.extension(name: str) → str[source]#

A file’s type, by its name: .jsonl.gz, .pdf; empty when it has none.

In lower case. An ending of digits alone is passed over, so that app.log.1 is a .log and data.20240101 has no type; an ending that does not look like a type (:data:_TYPE) is none. A compressed file keeps the ending before its compression’s, so that x.jsonl.gz and y.csv.gz are told apart.

chartbook.files.listing_root(declared: Union[str, pathlib.Path]) → pathlib.Path[source]#

The folder an asset’s files are listed from: a folder itself, a glob’s fixed prefix, a file’s own folder.

chartbook.files.partitions(relative: str) → dict[str, str][source]#

The key=value folders of a file’s path inside its asset, in order: {"year": "2024"}.

Only folders count, not the file’s own name, as a reader of Hive’s layout takes them. A folder whose key is empty is not one. The path is as a record writes it, with / between folders; a \ is part of a name.

chartbook.files.path(ref: Union[str, chartbook.refs.AssetRef], project_dir: Optional[Union[str, pathlib.Path]] = None) → pathlib.Path[source]#

Get the path the manifest declares for a files asset of the current pipeline.

from chartbook import files files.path(“earnings_releases”) # doctest: +SKIP

This is :func:chartbook.assets.path with kind="file": it answers for files assets and nothing else. The path is the file, the folder, or the glob as declared; :func:chartbook.assets.files gives the files themselves. Nothing checks that it exists, so a build can ask where to write before anything is there.

A files asset of another pipeline is named with the pipeline in front, files.path("filings:earnings_releases"), and is the copy that chartbook.lock pins.

Parameters:

  • ref – The asset’s name: its key in [files].

  • project_dir –

    Where to look for the pipeline, as for

    func:

    chartbook.assets.path.

Returns:

The absolute path declared for the asset.

Raises:

  • AssetNotDeclaredError – If the manifest declares no such asset.

  • ValueError – If the reference names another kind of asset.

chartbook.files.preview_of(listed: list, root: Union[str, pathlib.Path]) → Optional[dict][source]#

What a files asset’s page previews: the first file in its listing that a preview can show.

Parameters:

  • listed – The files, as the index lists them (path relative to root, and size_bytes), in order.

  • root – The folder they are listed from.

Returns:

{"path", "kind", "file"} (the file on disk), with text for a text file; None when no file listed is one to preview, or the first that is cannot be read. An image larger than

data:

THUMBNAIL_BYTES is not previewed.

chartbook.files.preview_text(file: Union[str, pathlib.Path]) → Optional[str][source]#

The first lines of a text file, for a page: None if it is not text, or cannot be read.

At most :data:PREVIEW_BYTES are read (decompressed, for gzip;

Func:

_bounded). A line that is a JSON object or array is pretty-printed, and then at most :data:PREVIEW_LINES lines are kept, each cut to :data:PREVIEW_LINE_LENGTH characters. A line cut short by the limit is left out. Bytes that are not UTF-8, or a NUL, say it is not text.
