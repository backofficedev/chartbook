chartbook.backends.databricks#

Databricks: a source in a Databricks SQL warehouse. Experimental.

An early experiment: tested against a stand-in for the warehouse (tests/mocked_databricks.py), not yet against a real workspace. See the roadmap in the documentation.

::

[sources.warehouse]
backend = "databricks"
url = "databricks://dbc-a1b2c3d4-e5f6.cloud.databricks.com?http_path=/sql/1.0/warehouses/abc123&catalog=main"

[dataframes.curve]
source = "warehouse"
table = "main.rates.curve"

The URL names the workspace’s host, the warehouse’s HTTP path (its “Connection details” show both), and optionally the catalog and schema a name without them is found in. Every part is optional in a manifest, since the machine may supply it; a manifest’s URL names no user, no token and no way of signing in. The driver is the Databricks SQL connector, which pip install chartbook[databricks] installs.

The host comes from the machine, and so does the token. A token is sent only to a host this machine names: the host of the machine’s URL for the source (CHARTBOOK_SOURCE_<NAME>_URL or ~/.chartbook/sources.toml, databricks://token:<token>@<host>?http_path=…), or else DATABRICKS_HOST, with DATABRICKS_TOKEN, the engine’s own variables. A manifest’s host, or the host in another pipeline’s record, is checked against it and never used in its place: a manifest or a store anyone can write must not be able to send this machine’s token somewhere else. The HTTP path is the machine URL’s, else the manifest’s, else DATABRICKS_HTTP_PATH. auth=oauth in the machine’s URL signs in through the browser instead of a token, once for the life of the process.

A pipeline’s SQL runs with this machine’s credentials in this machine’s workspace: building a pipeline someone else wrote runs their queries as you, as running their code does.

Reading. :meth:DatabricksBackend.sql asks the warehouse for the query’s columns at once, so a name it does not know is refused then, and returns a lazy frame that runs the query when it is collected, a batch at a time; head(n) with nothing filtered asks for n rows. ChartBook runs nothing but select on its own account; the SQL a person runs through data.sql() or data.connect() is between them and the warehouse.

sql(query: str)[source]#

Run SQL in the warehouse, as a Polars LazyFrame.

The warehouse binds it now (select * from (…) limit 0), so a name it does not know is refused at once, and its columns are the frame’s schema; should the connector give an empty result no columns, one row is asked for instead, and failing that the schema is read from the type names the warehouse gives. Collecting the frame runs it, and each batch is checked against that schema. An error found while collecting comes as Polars’ ComputeError with the warehouse’s message in it, or as the

Class:

~chartbook.backends.BackendError itself, by Polars version.

Raises:

chartbook.backends.BackendError – If the warehouse refuses the query, with its message.

chartbook.backends.databricks.connection_for(source: Optional[str], public_url: str) → chartbook.backends.databricks.Connection[source]#

How a source is reached from this machine; see the module’s text for the rules.

Parameters:

  • source – The source’s name, by which the machine’s URL is found.

  • public_url – Its URL as the manifest, or another pipeline’s record, has it. Its host is a check; a user or a password in it is never used.

Raises:

chartbook.backends.BackendError – If this machine does not say enough to connect, or names another host than the manifest. The message never holds a token.

chartbook.backends.databricks.host_of(text: str) → str[source]#

A workspace’s host as it is compared, the host name alone in lower case; empty if text gives none.

host, https://host/, host:443 and https://host/?o=123, as a workspace’s address is written, all give host.

chartbook.backends.databricks.parse_url(url: str) → chartbook.backends.databricks.DatabricksURL[source]#

Read a databricks://[token:<token>@]<host>?http_path=…&catalog=…&schema=…&auth=… URL.

Raises:

ValueError – If it is not one: another scheme, a host that is not a host name, a path after the host, a port, an option that is not one of :data:URL_OPTIONS, an option given twice, a fragment, or an auth that is not token or oauth. The message repeats nothing of the url, which may hold a token anywhere.
