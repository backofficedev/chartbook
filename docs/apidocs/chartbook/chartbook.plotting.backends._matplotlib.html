build_figure(df: pandas.DataFrame, config: ChartConfig | DualAxisConfig, overlay: chartbook.plotting._types.OverlayConfig) → tuple[matplotlib.figure.Figure, matplotlib.axes.Axes][source]#

Build a matplotlib figure and axes for the given chart config.

This is used by ChartResult.mpl_figure and ChartResult.mpl_axes for lazy access to matplotlib objects for fine-grained customization.

Parameters

df : DataFrame Data to plot. config : ChartConfig | DualAxisConfig Chart configuration. overlay : OverlayConfig Overlay configuration.

Returns

tuple[Figure, Axes] The matplotlib Figure and Axes objects.
