chartbook.diagnostics.build_diagnostics(manifest: dict[str, Any], skip_pipelines: collections.abc.Iterable[str] = ()) → list[chartbook.diagnostics.DiagnosticRow][source]#

Generate diagnostics rows for all pipelines, dataframes, charts and models.

Required fields come from the manifest’s [policy] section when present (catalogs), otherwise from the default lists in this module.

Parameters:

skip_pipelines – Pipelines left out of this build (--no-strict skips one whose files are missing): not part of the site, so not in its report either.

chartbook.diagnostics.generate_metadata_diagnostics(manifest: dict[str, Any], docs_build_dir: pathlib.Path, skip_pipelines: collections.abc.Iterable[str] = ()) → list[chartbook.diagnostics.DiagnosticRow][source]#

Create the metadata diagnostics CSV inside the docs build directory.

Returns:

The diagnostic rows, so callers can enforce strict policy.

chartbook.diagnostics.get_active_policy(manifest: dict[str, Any]) → dict[str, Any][source]#

Return the manifest’s resolved policy, or the default warn-only policy.

Catalog manifests carry a resolved policy key; standalone pipelines fall back to the defaults.
