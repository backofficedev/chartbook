# Data Sources

Details about the data sources used in this pipeline.

## Federal Reserve Board

The Federal Reserve provides the fitted yield curve parameters and zero-coupon
yields via the FEDS 200628 dataset. This dataset is updated daily and contains
yield estimates for maturities ranging from 1 to 30 years.

- [FEDS 200628 Data](https://www.federalreserve.gov/data/yield-curve-tables/feds200628.csv)

## FRED

Selected macroeconomic and financial time series from FRED (Federal Reserve
Economic Data), maintained by the Federal Reserve Bank of St. Louis.

- [FRED Homepage](https://fred.stlouisfed.org/)

## Office of Financial Research

Short-term funding monitor data including repo rates, sourced from the Office
of Financial Research's public API.

- [OFR Short-Term Funding Monitor](https://www.financialresearch.gov/short-term-funding-monitor/)
